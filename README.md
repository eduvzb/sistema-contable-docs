# Braval — decisiones y specs

El código y las pruebas están en los repositorios hermanos de backend y frontend. Este repositorio conserva decisiones de dominio y requisitos que necesitan acuerdo; una spec no es obligatoria para cada tarea.

- [Guía de trabajo](AGENTS.md): reglas breves para cualquier agente o persona.
- [Principios](docs/constitution.md): decisiones duraderas para orientar cambios.
- [Cuándo usar una spec](docs/flujo-spec.md): flujo según el riesgo.
- [Fuentes de dominio](docs/fuentes.md) y [Planeación](docs/planeacion/00%20-%20Inicio.md): contexto, no sustituyen el producto actual.
- [Índice de specs](specs/README.md): criterios existentes y estado documental.
- [Ejemplo breve](docs/ejemplo-flujo-breve.md): pequeña corrección frente a decisión compleja.

Para un cambio pequeño: investiga, implementa y prueba. Para una decisión de negocio o contrato nuevo: acuerda resultados observables antes de codificar. PR y herramientas de agentes son opcionales.
