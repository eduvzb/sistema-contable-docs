# Contexto de dominio

Estos documentos ayudan a preparar cambios del producto. El código y las pruebas muestran lo implementado; las [specs](../../specs/README.md) organizan el trabajo pendiente.

- [Alcance del producto](003%20-%20Alcance%20del%20producto.md): capacidades descritas y posibles ampliaciones.
- [Reglas de negocio](005%20-%20Reglas%20de%20negocio.md): restricciones para contrastar con el cambio solicitado.
- [Escenarios contables](004%20-%20Escenarios%20contables.md): ejemplos y casos límite.
- [Preguntas abiertas](006%20-%20Preguntas%20Abiertas.md): cuestiones que aún pueden requerir validación.
- [Glosario](002%20-%20Glosario.md): términos del dominio.
- [Análisis inicial](001%20-%20An%C3%A1lisis%20Inicial%20del%20Proyecto.md): contexto de descubrimiento.
- [Guía de conceptos](Conceptos/Gu%C3%ADa%20de%20conceptos.md) y [guía de escenarios](Conceptos/Gu%C3%ADa%20Explicada%20de%20Escenarios%20Contables.md): material explicativo.

Consulta sólo las fuentes pertinentes al criterio que estés preparando. Una propuesta de estos documentos no sustituye una instrucción actual del usuario ni demuestra que el producto ya la implementa.
